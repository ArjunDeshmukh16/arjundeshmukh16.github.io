# Arjun Deshmukh Portfolio

Original React and TypeScript portfolio design, with public content aligned to the approved October 11, 2026 resume.

- Edit public contact details, experience, projects and skills in `src/content.ts`.
- Replace `public/docs/Arjun_Deshmukh_Resume.pdf` with the exact approved PDF. Both resume buttons use this path.
- `GITHUB_PROFILE_README.md` mirrors the GitHub profile copy; keep both aligned when editing.
- The contact form opens an email draft to the configured contact email. It does not submit messages to a third-party service.

## Build

```sh
npm ci
npm run build
```

GitHub Pages deploys the production build from main. Keep private application records and inbox data out of this public repository.
